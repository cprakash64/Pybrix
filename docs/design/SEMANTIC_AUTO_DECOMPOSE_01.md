# Semantic Auto decomposition

Automatic is the default model mode. A generic, bounded semantic response describes an object and a hierarchy of parts rather than choosing a fixed object taxonomy. Character and Vehicle remain optional legacy compatibility modes until separately authorized live inference evaluation provides evidence for removing them.

The geometry worker owns preparation and realization. It labels exact connected components, renders six deterministic normal views and six color component maps, and retains front-most face IDs and depth locally. Only PNGs and bounded scalar component summaries cross the analysis boundary. Projection matrices, face IDs, depth, source buffers and triangle membership never leave the worker. One preparation is retained for at most 240 seconds, consumed when suggestions are made, and released on cancellation, errors or disposal.

The response permits at most 24 parts, eight major parts, depth four, twelve repeated instances, two polygons per view and twelve points per polygon. IDs and labels are bounded; parents must exist and form an acyclic tree. Polygon, metadata, image and total request limits are validated before a provider call. Provider replies and worker inputs are validated independently.

Local correspondence intersects normalized view regions with front-most component pixels. A component must have at least 82% coverage in two views, consistent coverage in other supplied views and sufficient region purity. Explicit component IDs cannot override these checks. Whole-object shells cannot masquerade as small parts. Repeated groups require measured spatial separation and balanced cluster sizes. Component and semantic confidence remain separate; unsupported recognition never creates an executable extraction.

Component extraction preserves source triangles and coordinates. Major solid assemblies may propose an infinite plane; local correspondence checks both selected half-space and annotated region coverage. Nine nearby offsets may refine a common plane using source triangle intersection lengths. Complementary halves refine together. Sibling membership conflicts are refused. The existing split Preview validates the physical result, and its existing commit and Undo remain the only authority that changes the document. No new Boolean or arbitrary local cut is implemented.

Initial single-source models use entire-model scope. After partitioning, analysis is scoped to the selected piece. Aggregation across independent document parts is deferred. Revision changes invalidate suggestions and require another analysis. Normal results show major assemblies, with detail hierarchies under More and Show parts. Technical evidence stays out of default rows.

Work is bounded independently of the two-million-face ceiling: 8,192 locally labeled components, 64 admitted metadata components, 128 million raster pixels, 64 million scan rows, 64 million region pixels and 48 million scored faces. Checkpoints cover preprocessing, rendering, correspondence, grouping and refinement. Semantic raster clipping is conservative and uses the unchanged barycentric depth test; legacy rendering and qualified Manual split and Repair algorithms remain unchanged.

Synthetic semantic annotations and actual-truck annotations are test-only fixtures. Production dependency and bundle checks prohibit their inclusion. Mock qualification demonstrates local determinism and operation safety, not live model recognition quality. A separate live evaluation must assess free labels, hierarchy, regions, repeated instances, refusal accuracy, latency and request budgets across unseen objects before deployment is considered.
