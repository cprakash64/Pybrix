# Repair and Split: intent first

Functional baseline: `b4992311858c8437fdbd44bf616a5f9982fd231e`.

The left panel presents the current action. Model information remains available through deliberate Details, Advanced, or Inspector access. Disclosures retain their mounted operation owners: opening a section never restarts analysis or releases a repair candidate.

## Repair

The normal Repair model action arms one validated repair continuation. The existing controller builds and checks the candidate, then the UI requests the existing guarded commit. Only the explicit action arms it; changing document, revision, or part retires that intent. Cancellation and failure disarm it. Advanced Preview repairs retains explicit Preview → Apply → Undo for expert review and regression testing.

The default result says Repair complete, with either Your model is ready or the protective explanation for geometry left unchanged. Continue and Undo remain available. A healthy model offers Done. A model with no safe changes offers Continue, without blocking other tools.

Details holds diagnostics and issue navigation. Advanced repair options retains individual operation toggles, opening repair, candidate review, applied repair details and the original limits. Diagnostic counts use neutral typography rather than a severity dashboard.

## Split

Auto and Manual use the existing keyboard tab control. Auto replaces setup with progress and then results. The approved network/privacy disclosure stays explicit before analysis. Each result has a part name, a plain availability sentence and Preview. Only one available row receives primary emphasis. Per-row Details retains the reason, operation, viewport visibility and Edit. Adjust cut holds the plane editor and Preview adjusted cut. Component selection remains available for advanced review.

Manual presents axes and a position slider, with viewport dragging guidance. Numerical position, tilt, roll, reset and swap sit in Advanced. Connector settings are collapsed; requesting a physical connector on a unitless model opens the existing unit chooser. Presentation intent is scoped to the document; the qualified sizing/controller path is unchanged.

Preview disclosure state holds only a scalar candidate key, never a render snapshot or geometry buffer.

Preview replaces setup with two pieces and Apply split. Adjust cut reveals editing on request. Applied replaces setup with Split complete, Export pieces and Undo; Split again retains successive-cut capability. Details retains piece metrics, viewing modes and export format choices. Volume is shown only when the qualified result marks it interpretable.

## Feedback and accessibility

Normal states are quiet live status. A refused local cut is a neutral actionable limitation; detailed worker reasons are disclosed. Runtime or commit failures use an alert with plain failure copy and disclosed technical information. Repair/Split operation alerts use restrained amber treatment. Integrity guards remain authoritative; no diagnostic count implies danger to the source document.

The Model details shortcut opens the Inspector at both docked and drawer widths, without switching the active tool.

Activity is a native collapsed disclosure and absent when empty. Its summary participates in the drawer focus trap, which excludes hidden/inert controls and closed disclosure contents. Existing semantic controls, visible focus and operation announcements remain in place. Workspace navigation focuses the visible action heading; collapsed diagnostics never compete for focus. The automatic-repair explanation remains reachable from Details when Continue replaces the footer. No animation or dependency is added.
